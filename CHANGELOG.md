## [1.0.2] -2026-10-22

### Added

- Added more key-binds.
- Added Options page for more usability.
- Added interface customization in Options page
- Light / Dark theme option included.
- Custom button color option included.
- Multiple font option i.e. Sans-Serif, Serif, Monospace with default being System font is included.
- Dynamic Heading font size change option (in px) is included.
- Lastly, custom UI can be made using a Stylesheet Language (CSS) to completely change the layout, colors, animation, sizing, font, size etc. by importing a local .css file in Custom CSS / UI option in Interface of Options page.
- Added the default key-binds list into Options page for easier understanding.
- Added an About section in Options page to add credits, version info and details in the application.
- Added a spinning thumbnail art on bottom right of the main section to cure boredom.
- Added music metadata capture.
- Added Linux native MPRIS media support for seamless control of the application.
- Added Drag and Drop feature to add the music to queue.
- Added CLI support. (For e.g. - ./musicplayer_1.0.2_amd64.AppImage "/home/USER/Music/Rick_Roll.flac")
- Added Full Screen Now Playing feature.
- Added support for non-bleeding-edge Linux distributions. (E.g. - Fedora, Debian etc.)

### Fixed
- Optimized for smaller windows.
- Changed the UI with a card layout rather than a list layout in Search and Stream section.
- Optimized the UI to make it more interactive.
- Fixed Bugs.
